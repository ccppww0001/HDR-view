# vivo 高光重建研究记录

## 当前结论

截至 2026-11-17，四张 Neo9 Pro 样本证明私有辅助 JPEG 与主图高光存在空间对应，但没有足够资料确定 vivo 的光强单位、传递函数、遮罩及局部色调映射。

因此，项目的候选模型是**研究用、可解释、受限高光重建**，不是 vivo 官方算法，也不宣称已复现手机 XDR 观感。首版无受控拍屏参考，报告必须固定 `xdr_appearance_verified=false`。

## 实测诊断（主图与辅助图均先经 ICC 转 sRGB，亮度为 Rec.709 系数）

| 样本 | 辅助亮区比例（>8/255） | 辅助亮区落在主图最亮 5% 区域的比例 | 主辅亮度相关系数 |
|---|---:|---:|---:|
| IMG_20261111_175548 | 2.896% | 80.84% | 0.401 |
| IMG_20261111_175601 | 7.007% | 54.71% | 0.453 |
| IMG_20261116_212648 | 0.312% | 98.53% | 0.310 |
| IMG_20261116_212653 | 0.330% | 98.21% | 0.323 |

这些结果支持“辅助图是高光相关的空间图”，不支持直接把其像素解释为增益、线性残差或真实曝光。夜景辅助图只含极少灯点，与较低 `maxGain` 一致，但不能反推相册是否点亮。

## 候选模型

- `additive-residual`：主图 + 辅助亮度×scale，限制在高光覆盖区与增益 cap 内；阈值到两倍阈值采用连续平滑步进融合，不再硬切换。
- `ratio`：辅助亮度映射为受限比值；`maxGain` 仅作 cap，不直接写入标准元数据。
- `short-exposure`：仅表示曝光辅助假设的近似试验，不证明存在短曝光原图。

三个模型不能串联，默认输出均带 `research_only=true`。纯黑辅助图严格回到主图，黑色/暗区不能因除零或非有限值被放大。

## 色彩

辅助图保持 Display-P3 → linear Rec.709 → linear BT.2020，避免先转 sRGB 丢弃高光色域。主图经嵌入 ICC 到 sRGB，再线性化并转 BT.2020。几何缩放使用 OpenCV 双线性插值，尚无证据证明像素级对齐或官方滤波器。

## 显示目标

重建结果与显示目标分离。HDR400 输出对高于 203 尼特参考白的 BT.2020 亮度使用连续单调有理曲线，保持 RGB 比例，拐点默认 0.8；HDR1000 不使用该压缩。映射不恢复已削顶的 JPEG 细节，也不构成手机 XDR 观感验证。HDR400 JPEG 与 JPEG XR 来自同一映射结果。

## 停止条件

没有更多公开资料或受控参考时，只交付“合理 HDR 重建，手机 XDR 观感未验证”。若输出出现全图变亮、光晕、霓虹褪色、灯点错位或数值溢出，应停止正式输出，不用全局滤镜掩盖。
